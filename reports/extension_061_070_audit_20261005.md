# Extension Batches 061–070 production-readiness audit

Audit date: 2026-10-05. Dataset revision: `ff7e738f03134796fb6422502b6d39f0c0ed5983`.

**Decision: do not release these ten extension batches to production yet.** All existing structural validators pass, but targeted editorial checks found defects those validators do not detect. No dictionary data, manifests, lookup indexes, allowlist entries, or frozen assets were changed during this audit.

## Confirmed defects and editorial concerns

### 1. Open phrases incorrectly joined into single-word headwords

Batch 063 contains these entries, each also present in `extension_closed_compound_allowlist.txt`:

| Stored headword | Established spelling | Source |
| --- | --- | --- |
| `toiletrybag` | toiletry bag | [Cambridge](https://dictionary.cambridge.org/dictionary/english/toiletry-bag), [Oxford](https://www.oxfordlearnersdictionaries.com/us/definition/english/toiletry-bag) |
| `waterbottle` | water bottle | [Cambridge](https://dictionary.cambridge.org/dictionary/english/water-bottle) |
| `ricecooker` | rice cooker | [Cambridge](https://dictionary.cambridge.org/dictionary/english/rice-cooker), [Oxford](https://www.oxfordlearnersdictionaries.com/us/definition/english/rice-cooker) |
| `foodprocessor` | food processor | [Cambridge](https://dictionary.cambridge.org/us/dictionary/english/food-processor) |
| `airvent` | air vent | [Cambridge's air vent collocation](https://dictionary.cambridge.org/us/dictionary/english/vent) |

These violate the project's rule against deleting separators to create headwords. Their stored plurals inherit the invalid spelling. They also fail the intended subtitle lookup behavior because actual subtitle tokens are separate words. The allowlist currently prevents the validator from raising these entries.

A full automated WordNet spelling comparison identified 117 review candidates: 12 in Batch 061, 40 in Batch 062, and 65 in Batch 063. These are **candidates, not 117 confirmed errors**: older WordNet spellings differ from valid modern closed compounds such as `roadmap` and `carpool`. Current dictionary verification is necessary for each candidate. The confirmed examples above are not an exhaustive inventory of joined phrases; WordNet also does not cover every modern expression.

### 2. Missing useful inflected lookup keys

Fifteen verb entries in Batch 061 store no forms:

`deplatform`, `shadowban`, `prebunk`, `gamify`, `photobomb`, `misgender`, `overshare`, `crowdsource`, `upsell`, `downsell`, `rewild`, `weatherize`, `circularize`, `terraform`, `declutter`.

Examples of missing keys absent from the entire combined lookup namespace:

- `gamifies`, `gamified`, `gamifying` for `gamify`.
- `deplatforms`, `deplatformed` for `deplatform`.
- `weatherizes`, `weatherized`, `weatherizing` for `weatherize`.
- `declutters`, `decluttered`, `decluttering` for `declutter`.

Current dictionary evidence: [Cambridge gamify](https://dictionary.cambridge.org/us/dictionary/english/gamify), [Cambridge gamified](https://dictionary.cambridge.org/us/dictionary/english/gamified), [Cambridge deplatform](https://dictionary.cambridge.org/us/dictionary/english/deplatform), [Collins weatherize](https://www.collinsdictionary.com/us/dictionary/english/weatherize).

Useful count-noun plurals are also missing, including `deportees` (064), `pledgers` (064), `technophobes` (065), `hatmakers` (066), and `honeymooners` (066). Each corresponding headword has an empty forms array, and each plural is absent from the combined lookup index.

Some participles are already separately owned, including `deplatforming`, `shadowbanning`, `oversharing`, `crowdsourcing`, `rewilding`, and `terraforming`. These must not be added as conflicting forms. Repair must preserve ownership rules and add only currently unowned, manually checked forms.

The general verb audit returned 383 rows for review. Most flags are not necessarily defects: mixed POS entries can validly store noun plurals, legitimate irregular forms can disagree with the morphology library, and suggested forms can already belong to frozen entries. After accounting for global ownership, seven entries still had unowned library suggestions; several suggestions were plainly unsuitable, such as `unmaked`, `unbended`, and `betrode`. No automatic repairs were applied.

### 3. Burmese sense selection needs further review

Batch 061 `circularize` currently describes changing a business/product system into a resource-reusing circular-economy model:

> လုပ်ငန်း သို့မဟုတ် ထုတ်ကုန်စနစ်ကို အရင်းအမြစ်ပြန်သုံးသည့် ပတ်လည်စီးပွားပုံစံအဖြစ် ပြောင်းသည်

This narrow business interpretation omits the established senses: distributing circular notices, polling by questionnaire, publicizing, or making something circular. It needs editorial correction or strong lexical support before inclusion as the sole subtitle gloss. See [Merriam-Webster circularize](https://www.merriam-webster.com/dictionary/circularize) and [Collins circularize](https://www.collinsdictionary.com/us/dictionary/english/circularize).

## Release and review limits

- The frozen `dist/dictionary_v1.json` still contains exactly 30,000 entries. Its committed and LF-normalized working SHA-256 both match the recorded release hash: `fcdb26986ed62bfaa130732ed0e88cc2e30bbc7f964b4b16de47f809783ed325`.
- `dist/` contains the frozen dictionary and phrase releases; there is no packaged extension release artifact. A production loader may support source batches separately, but no application loading/integration test was performed here. A 35,000-headword manifest alone does not establish that the production application loads 35,000 entries.
- A systematic sample of 100 entries, ten per batch, plus targeted findings was inspected for editorial concerns. Every entry received structural checks, but this was not a full bilingual review of all 5,000 entries or a complete General American IPA audit. No native-speaker approval is claimed.
- README still says extension next batch 061; the canonical extension manifest correctly says 071.

## Repair priorities before release

1. Review compound spellings in Batches 061–063 and the allowlist. Replace invalid joined expressions with verified new single-word vocabulary, keeping exactly 500 entries per batch.
2. Repair missing useful forms across all ten batches while preserving global key ownership.
3. Review Burmese senses and General American IPA, beginning with the flagged entries, then complete the intended editorial sign-off.
4. Strengthen lexical/morphology review so a passing structural validator cannot be mistaken for editorial approval. Remove invalid allowlist entries and retain evidence for accepted compounds.
5. Revalidate and rebuild the extension index after corrections; package the extension separately from frozen v1 and test its actual application loading and lookup behavior. Update stale extension documentation.

Machine-readable automated results and spelling candidates are in `extension_061_070_audit_20261005.json`. Raw morphology suggestions are diagnostic leads, not approved corrections.
