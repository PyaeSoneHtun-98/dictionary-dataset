# Agent A editorial review

The final candidate set is `selected_entries.json`; it is a list of runtime entry objects, deliberately below the original 1,500 target after the user's quality-first steering. Root will combine and renumber candidates into complete 500-entry batches.

Selection favored useful conversational insults, personality/emotion vocabulary, narrative description, practical trades and objects, ordinary medical-documentary concepts, and missing contemporary words. More than 300 initially authored candidates were pruned for narrow technical use, archaic status, needless elaboration, or redundant spelling. Low-value Latin plant/animal taxonomy and British spelling alternatives were not used to fill the quota. `prune.txt` is a staging editorial exclusion list, not a declaration that every excluded item is invalid English.

The three authored PSV files preserve independently written Burmese glosses. In those sources, `c` marks a manually chosen count noun, `n` a noun for which no plural was requested, `v` a verb, `a` an adjective, and `r` an adverb. `form_review.json` contains proposed, stored, and excluded forms. All stored forms were reviewed; irregular `rewound`, `flyleaves`, `noblewomen`, and `countersank/countersunk` were checked. Fixed `dunno` does not inflect; Japanese `sensei` has an unchanged plural. The verb `psych` uses `psychs`, rather than the noun spelling `psyches`.

General American IPA for missing CMU entries was manually authored in `ipa.psv`. Available CMU pronunciations were also reviewed; stress/consonant boundaries were corrected for concavity, servility, squashy, persuadable, goodnight, shithole, and the verb rewind. `ipa_review.json` records the final pronunciation and resource/manual provenance. No selected pronunciation is missing, contains whitespace, or represents a glued multi-word expression.

`lexical_review.json` retains exact current dictionary URLs for every selected compound-looking/validator-flagged spelling and modern addition. Current Collins, Cambridge, Oxford, Dictionary.com, and American Heritage entries were consulted. Several valid closed variants coexist with open or hyphenated spellings, including crawlspace, cabinetmaker, stationmaster, standalone, and semiofficial. Derivative false positives were reviewed against actual dictionary entries or expressly listed derivatives, rather than treated as accidental glued compounds. Collins marks Breathalyzer as a trademark, so it was removed. Dictionary.com redirects laxness to the novelist Laxness; the common abstract noun was instead verified as an explicit derivative under Collins `lax`.

`verify.py` checks entry fields, POS, gloss limits, IPA alphabet/whitespace, exclusive hash partition, head/form uniqueness and all 54,600 existing lookup keys. Root still must remove any proposed form collisions with other agents' new headwords/forms and run the canonical extension validator against the final complete batches.
